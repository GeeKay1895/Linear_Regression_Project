# Model building - Linear Regression
X = df[['YearsExperience']]
y = df['Salary']

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)

r2 = r2_score(y, y_pred)
r2
Out[10]:
0.9569566641435086

The linear regression model achieved an R² score of approximately 0.95, indicating excellent predictive performance.
